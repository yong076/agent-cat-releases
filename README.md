# Agent Cat Downloads

This repository hosts public DMG downloads for Agent Cat.

Agent Cat is a macOS menu bar utility that watches local Codex, Claude Code,
and Gemini CLI activity through local metadata and connector snapshots. The
private product source code is not stored in this repository.

## Download

- Latest release: https://github.com/yong076/agent-cat-releases/releases/latest
- Current beta: https://github.com/yong076/agent-cat-releases/releases/tag/v26.19.0

## Install

1. Download the DMG from the release page.
2. Open the DMG and drag `Agent Cat.app` to `Applications`.
3. Open Agent Cat from `Applications`.
4. If macOS blocks the unsigned tester build, right-click the app and choose
   `Open`, or use `System Settings > Privacy & Security > Open Anyway`.
5. Follow the first-run setup wizard to install the local connector.

## Privacy

Agent Cat is designed to read local activity metadata and usage snapshots. It
does not intentionally store prompt text, message content, transcripts, or
conversation bodies.
